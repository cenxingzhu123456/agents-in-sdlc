**[GitHub Copilot CLI][about-copilot-cli]** は、GitHub Copilot をエージェント型コーディングアシスタントとしてターミナルで利用できるようにします。コードベースを探索し、コードを生成し、コマンドを実行し、外部ツールに接続できます。コマンドラインだけで作業できるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローを実践します。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の小さな変更を加え、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. 絞り込み issue から始め、Plan モードで方針を定め、Autopilot モードで実装して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、絞り込み機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーで絞り込みの動作を確認します。
7. 品質保証 (QA) カスタムエージェントを作成して使用し、要件、カバレッジ、検証の証拠を確認します。
8. 絞り込み機能全体をレビューし、その PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、クラウドへの任意の委任に使える便利なスラッシュコマンドを確認します。

ワークショップを分かりやすくするため、作成する PR は 2 つです。星評価の変更と、指示の更新、スキルの更新、QA プロファイル、テストを含む絞り込み機能の変更です。絞り込み機能と品質ワークフローは、1 つの会話とブランチで進めます。各ツールを学ぶなかで、それまでの作業を引き継げます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
